# Enable validated Original Object edits

Status: Accepted.

ADR-0003 kept Original Objects read-only because they lacked a validated identity and an editor-owned mutation boundary. The pre-mod baseline now supplies positive provenance, scene/path resolution is checked against the same runtime GameObject, and `LevelEditSession` owns mutable `modifications` and `deletions`. A selected locatable Original Object can therefore receive a transform modification even though it is not an Editable Overlay Placement.

A new transform-only operation uses the reserved type `editor-mode-empty`, a deterministic session-unique id, an empty condition, and an empty properties array. Imported type, id, condition, properties, and all transform fields not explicitly edited are preserved. There is at most one resolved operation for a scene/path; Apply Modify upserts that identity and replaces a deletion for it. Delete upserts a canonical deletion containing only scene and path, restores the imported transform and name before deactivating the authored live object, and replaces a modification for the same identity. Level Framework remains the persistence contract: the editor previews the operation live, but only an explicit Level Export writes canonical JSON.

Live application verifies that the type-specific modifier is available before changing the object. It then applies `BaseModifier` and only afterward the type modifier, so missing or throwing modifiers cannot leave a transform-only partial preview. Failures are itemized and the captured transform, active state, and name are restored without committing session state or rewriting the source file. `editor-mode-empty` is a temporary Editor Mode creator whose modifier performs no name or component mutation. A portable `empty` creator in Level Framework Extended is the intended long-term replacement; migrations to that portable type remain a separate change.

Imported modifications and deletions keep their source array order. If more than one operation resolves to the same scene/path, every source entry remains present and read-only until the user explicitly keeps one; that choice removes the competing entries as one reversible Original Object history command. An untouched imported operation cannot be removed. A locatable pending operation may be removed: a new operation restores the transform, name, and active state captured in the pre-mod Original Object baseline, while a pending replacement of an imported operation restores that imported operation and its import live state.

Original Object history is independent from Editable Overlay Placement history. Undo and redo restore both the session arrays and the recoverable live state, including the imported active state when a modification replaces a deletion. A preview persists while Editor Mode is closed and reopened, and ends at room unload, Reset, operation replacement or removal, Room Overlay replacement, or session teardown. Reset restores the entire session to the imported snapshot and clears both page histories.
