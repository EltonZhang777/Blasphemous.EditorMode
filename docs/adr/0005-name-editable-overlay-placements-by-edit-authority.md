# Name Editable Overlay Placements by edit authority

Status: Accepted; code migration pending.

`Architect-owned` implied that an object's origin determined whether it was editable, but the editor treats every validated addition admitted to the Level Edit Session as editable, including imported additions. The canonical term is therefore `Editable Overlay Placement`, which describes edit authority rather than provenance; `Preserved Addition` is excluded. Keeping the old name or narrowing it to author-created additions would preserve the provenance/authority confusion. The code rename is tracked separately and is not evidence that migration has already happened.
