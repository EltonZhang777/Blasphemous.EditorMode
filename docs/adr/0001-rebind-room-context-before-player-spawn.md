# Rebind the room context before player spawn

Blasphemous.ModdingAPI routes `OnLevelPreloaded` from the game's `LevelManager.OnLevelPreLoaded`, before enemy and player spawning. On the first room, the active initializer's `LevelEffectsStore` property was not initialized at this boundary. Player effect components cache `Core.Logic.CurrentLevelConfig.LevelEffectsStore` during `Start`, so rebinding to an initializer based only on a child component's presence can cache a null store and break effects until the next room transition. Refresh only after the initializer's `LevelEffectsStore` property is non-null; otherwise keep the existing context and publish an actionable diagnostic.
