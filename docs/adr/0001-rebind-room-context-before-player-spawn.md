# Rebind the room context before player spawn

Blasphemous.ModdingAPI routes `OnLevelPreloaded` from the game's `LevelManager.OnLevelPreLoaded`, which runs after the logic scene becomes active and before enemy and player spawning. The first-room log showed the active initializer's `LevelEffectsStore` property was null at this boundary, so the existing property check left `Core.Logic.CurrentLevelConfig` stale and effects failed during spawn. Editor Mode now checks for the component in the initializer's hierarchy before rebinding; if it is absent, the refresh is skipped and an actionable ApplyReport is published.
